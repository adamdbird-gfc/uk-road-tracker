## Common acceptance checklist and historical applicability

For each case require physical route identity and relevant activity, exact source
and target endpoints, physical connectivity, ordered correspondence, proof the
alternative is not an untravelled shortcut, route-specific/canonical-union delta,
and an explicit assessment of whether preserved historical journey evidence covers
the approved source span. All remain incomplete; retrospective applicability is
**unknown**, and no historical journey or unlock has been changed.

A private-access tag is an observation, never an automatic rejection of a journey
or sole proof against physical equivalence. Existing mode metadata and route
identity still need evidence; this task does not redesign journey matching.
