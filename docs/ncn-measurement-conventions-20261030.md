# NCN geometric measurement convention inventory

30 October 2026. Audited source baseline `0f8199651dad6014410274dc1b968e2417efe1b2`.
This records inspected code, not a national data validation. All operational rules remain unchanged.

## Coordinate conventions

WGS84 inputs are longitude/latitude degrees. Neither spherical formula is an ellipsoidal survey measurement. Both spherical operational projections use radius 6371008.8 m. Straight segments join projected original vertices; neither densifies geodesics. No height is used.

**AEQD**: `scripts/ncn_trial/network_geometry.py:metric_projector`; spherical azimuthal-equidistant, origin at centre of official route-feature WGS84 bounding box. Radial distance from origin is preserved on the sphere; arbitrary local distances and angles are approximate. The code explicitly documents avoiding Web Mercator scale on long routes; it does not document why admission and correspondence should have different corridor classifications.

**Route EQ**: `scripts/ncn_trial/journey_replay.py:projector`; x=R radians(lon-lon0) cos(lat0), y=R radians(lat-lat0). Origin copied from route metadata, including admission's bounding-box centre. Reference latitude is origin latitude, not each segment's latitude. Away from that latitude, east-west scale relative to the sphere is cos(lat0)/cos(lat). Origin longitude is a translation for distance calculations; latitude changes horizontal scale. Changing it also changes metric-coordinate target hashes.

**Local EQ**: the same formula but with first source vertex or first network-edge endpoint as origin. This is a different metric space from Route EQ, even though the formula matches. Network edges do not share one planar metric origin.

**Provider XY**: Waymarked Web Mercator metres, radius 6378137, inverted to WGS84 before route geometry assessment. Original rounded provider coordinates do not establish OSM nodes.

## Interpretation

Different projection, different geometry evaluation, different sampling density, and different eligibility policy are four independent variables. AEQD and EQ corridor tests can be compared holding inputs and whole-edge policy fixed. Completion's clipped finite pair is a separate test even in one space. A finite pair is not a whole-edge admission, and a passing corridor does not override an explicit approved-span list, access, identity, modes or deferred masks.

The audited code documents spherical approximation and distinct policy purposes. It contains no discovered rationale promising that a 10 m admission corridor and a 10 m correspondence corridor have identical ground scale everywhere. This absence is an unresolved design/provenance issue, not proof of a historical author intention or a current credit defect.
