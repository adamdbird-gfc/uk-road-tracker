# Roadprints outline icons

Original editable vector icons shared by Journeys and Achievements. Each uses a 24 × 24 viewport, two-unit strokes, round caps and joins, and no fills. Android copies live in `app/src/main/res/drawable/ic_roadprints_*.xml`.

Tint at runtime: jade `#67D5CC` for transport; gold `#F7C450` for selected or unlocked states; muted `#B9C5D8` for locked states. Place icons inside the navy/blue surfaces used by Roadprints. Use 24–32 dp displays, with at least a 48 dp touch target for interactive controls. Keep a text label beside filter controls; icon shape and colour are supplemental cues.
