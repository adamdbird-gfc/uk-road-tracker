# UK Wetherspoons Collection map data

The venue names, label positions, towns, county grouping and OSM identities in
uk-wetherspoons-map-v1.json are derived from OpenStreetMap and are available
under ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/
Attribution: © OpenStreetMap contributors.
https://www.openstreetmap.org/copyright

The public editable map database and dated review ledger are published in
https://github.com/adamdbird-gfc/uk-road-tracker .
The candidate extract and its provenance are on the main branch in collections/.
County grouping uses the existing Historic County Borders Project Definition A
reference, https://county-borders.co.uk/, version 2026-10-06.

Individual public operator/CAMRA pages were checked for operating status only.
No directory extract, descriptions, photos, logos or official geometry is copied.
This is an independent, incomplete Roadprints beta map, not an official directory.
Map approval does not approve visit boundaries or award any visits.
