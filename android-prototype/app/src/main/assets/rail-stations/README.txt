This reference covers Great Britain stations listed by National Rail Darwin.
It does not establish platform identities or railway track alignment.
Code uses the supplied coordinates without modification. Radius rules live
in RailStationCatalog.java and are conservative capture heuristics.
Device positions are checked locally and are never sent to this data source.
